# Personal Portfolio

A modern personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive layout
- Hero section with introduction
- About, skills, projects, and contact sections
- Project cards with images and links
- Social links and contact information

## Files
- `index.html` - Main structure of the portfolio
- `style.css` - Styling for the design
- `script.js` - Interactive behavior
- `profile.jpg`, `weather-app.jpg`, `contact_form.jpg`, `countdown_timer.jpg`, `personal_portfolio.jpg` - Images used in the portfolio

## How to View
Open `index.html` in your browser to view the portfolio.

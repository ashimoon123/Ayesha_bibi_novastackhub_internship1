Enterprise Multi-Tenant Security Gateway

Production-grade Node.js/Express API security layer featuring hybrid JWT + OAuth 2.0 authentication, granular hierarchical Role-Based Access Control (RBAC), and OWASP Top 10 threat hardening.

🔑 Hybrid Auth: Local & OAuth 2.0 🔄 Tokens: Access + Refresh Rotation 🛡️ RBAC: SuperAdmin | Manager | Employee ⚡ OWASP: Helmet, CORS, NoSQL/XSS Sanitized 🍪 Storage: httpOnly SameSite Cookies

✨ Architecture & Security Capabilities

Engineered to defend enterprise services against identity spoofing and privilege escalation.

🔐

1. Local Authentication

Cryptographic password hashing powered by Bcrypt with salted rounds. Incorporates exponential backoff and automated account lockout thresholds to repel high-speed dictionary & brute-force credential stuffing.

Bcrypt 12 Rounds Account Lockout Timing-Attack Safe
🌐

2. OAuth 2.0 Federated Login

Delegated identity federations for Google and GitHub. Features cryptographically verified state parameters, automated tenant profile synchronization, and secure OAuth token exchange pipelines.

Google OAuth GitHub OAuth State CSRF Guard
🔄

3. Token Architecture

Dual-token lifecycle: Short-lived asymmetric Access Tokens alongside secure Refresh Token rotation. Persisted inside strictly isolated httpOnly, SameSite, Secure cookies to eliminate client-side token leakage.

15m Access Token 7d Refresh Rotation httpOnly Cookie
👑

4. Role-Based Access Control

Hierarchical privilege enforcement spanning SuperAdmin, Manager, and Employee tiers. Declarative route guards evaluate claims on every incoming dispatch following Principle of Least Privilege.

SuperAdmin Manager Employee Least Privilege
🛡️

5. OWASP Hardening

Defense-in-depth shield utilizing Helmet for CSP & HSTS security headers, origin-pinned CORS, sanitization filters mitigating NoSQL injections and cross-site scripting (XSS), plus windowed rate limiters.

Helmet Headers Express Rate Limit Anti-XSS / NoSQL

📋 Gateway Route Registry

Catalog of available API endpoints, required role permissions, and access models.

Method Endpoint Path Required Role / Permission Authentication Type Description
POST /api/v1/auth/login Public (Anonymous) Local Credentials Authenticates email/password, issues JWT Bearer token & sets refresh cookie.
GET /api/v1/auth/google Public OAuth 2.0 / Google Initiates Google federated OAuth 2.0 authentication flow.
GET /api/v1/auth/github Public OAuth 2.0 / GitHub Initiates GitHub federated OAuth 2.0 authentication flow.
POST /api/v1/auth/refresh Public / Valid Cookie Refresh Token Rotation Validates httpOnly refresh cookie, issues new access token pair.
POST /api/v1/auth/logout Authenticated JWT Bearer + Cookie Revokes refresh token in session registry and clears auth cookies.
GET /api/v1/employee/profile Employee, Manager, SuperAdmin JWT Bearer Returns profile data for the authenticated principal across all roles.
POST /api/v1/payroll/approve Manager, SuperAdmin JWT Bearer + RBAC Guard Approves company payroll transactions. Denies Employee role (403).
GET /api/v1/users SuperAdmin Only JWT Bearer + Strict RBAC Administrative tenant user directory. Denies Manager & Employee (403).

# Countdown Timer

A simple countdown timer webpage built with HTML, CSS, and JavaScript.

## Features
- Choose a target date and time manually
- Update the countdown by clicking the button
- Reset the timer anytime
- Stylish, responsive layout

## How to use
1. Open the index.html file in a browser.
2. Pick a date and time in the input field.
3. Click "Update countdown" to display the remaining time.
4. Click "Reset" to clear the countdown.

## Files
- index.html: page structure, styling, and countdown logic
